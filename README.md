# Fundamental Machine Learning

This repository contains coursework and projects completed as part of my M.S. in Business Analytics at Kent State University.

## Topics Covered

- Data preprocessing and exploratory data analysis
- Regression and classification
- Model training and validation
- Model performance evaluation
- Underfitting and overfitting
- Predictive analytics

## Tools and Technologies

- R
- RStudio
- Machine Learning
- Statistical Analysis
- Data Visualization

## Repository Purpose

The projects in this repository demonstrate the application of fundamental machine learning techniques to analyze data, build predictive models, evaluate model performance, and interpret results for data-driven decision-making.
